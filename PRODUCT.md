# CareSitter

CareSitter is a care booking platform with separate customer, caregiver, and admin experiences. Customers create care bookings for beneficiaries, caregivers receive matched offers and manage shifts, and admins review operational state.

The product UI is an authenticated task surface. Screens must prioritize clear status, reliable identity, and booking data that belongs to the signed-in account. Demo or mock data should not appear in production flows unless debug bypass mode is explicitly enabled.

Core data rules:
- Caregiver screens show only data for the authenticated caregiver profile.
- Booking cards, shift lists, schedules, earnings, and profile summaries must come from backend records keyed by booking id and caregiver id.
- Matching suggestions and offers are generated by the backend; the mobile apps display and act on those records instead of inventing local candidates.
- Empty states are valid when the database has no records for the current user.
